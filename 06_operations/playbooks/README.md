# Playbooks（業務手順書）

繰り返し実行する作業の手順を記録する。属人化を避け、再現可能にする。

## 最初に作るべき playbook

- `kickoff-board.md` — キックオフ取締役会の段取り
- `weekly-review.md` — 週次レビューの段取り
- `monthly-board.md` — 月次取締役会の段取り
- `decision-recording.md` — 決定事項を decisions.md と daily-log に正しく記録する手順

## テンプレート

```markdown
# Playbook: <作業名>

## 目的
（この作業で何を達成するか）

## 頻度
（毎日 / 週次 / 月次 / 随時）

## 担当
（誰が主導するか）

## 手順
1. ...
2. ...

## 完了条件
（何が成立したら完了か）
```
