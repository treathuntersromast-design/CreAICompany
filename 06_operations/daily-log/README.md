# 日次ログ

シャチョーが対話の末尾で更新する。「会社の毎日の足跡」を残す場所。

## パス規約

`YYYY/MM/YYYY-MM-DD.md`

例: `2026/06/2026-06-15.md`

## テンプレート

```markdown
# 日次ログ YYYY-MM-DD

## やったこと
- ...

## 決めたこと
- D-NNN: ...（決議番号で [../../01_board/decisions.md](../../01_board/decisions.md) と相互参照）
- ...

## 次の行動
- 誰が / 何を / いつまでに

## 未解決
- ...
```

## 運用ルール

- 1 日 1 ファイル。複数回の対話があった場合は追記。
- 決定が発生したら `01_board/decisions.md` にも同時に追記。
- 役員の発言は `[CTO]` `[CFO]` `[COO]` タグ付きで記録。
