# 週次レビュー

毎週末（金曜推奨）に COO 主導で実施する振り返り。

## ファイル名

`YYYY-WW.md`（W は ISO 週番号、ゼロ埋め）

例: `2026-24.md`

## テンプレート

```markdown
# 週次レビュー YYYY-WW

## 今週のサマリ
（daily-log を要約）

## OKR 進捗
- KR-1: 達成度 / 状況
- KR-2: ...

## INBOX レビュー
- 昇格判断: → [プロジェクト名](../../04_products/projects/<slug>/)
- 保留: ...
- 却下: ...

## リスク・課題
- ...

## 次週の重点
- ...

## 次回取締役会への提案
- [agenda.md](../../01_board/agenda.md) に積んだ項目
```
