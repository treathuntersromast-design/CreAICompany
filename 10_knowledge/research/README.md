# リサーチ

ファイル名: `YYYY-MM-DD_<テーマ>.md`

## ルール

- **出典必須**。URL・書籍・対話相手など、根拠を必ず明記する。
- 結論と事実を分けて書く。シャチョーの解釈は「考察」として別セクションに。
- リサーチ依頼の起点（誰が・なぜ依頼したか）を冒頭に書く。

## テンプレート

```markdown
# <テーマ> YYYY-MM-DD

## 依頼の起点
- 依頼者: シャチョー / @cto / @cfo / @coo / オーナー
- 目的: ...

## 事実
- ...（出典明記）

## 考察
- ...

## アクション提案
- ...
```
