# 決議ログ

取締役会で決定された事項を時系列で記録する。各決議は `D-NNN` で採番する。

## 書式

```
## D-NNN: <タイトル>
- **日付**: YYYY-MM-DD
- **議題**: 何を決めようとしたか
- **決定**: 決定内容（具体的に）
- **担当**: 誰が実行するか
- **期限**: いつまでに
- **関連議事録**: minutes/YYYY-MM-DD.md
- **関連 daily-log**: 06_operations/daily-log/YYYY/MM/YYYY-MM-DD.md
```
