# 取締役会議事録 2026-06-15（キックオフ）

## 出席者

- オーナー
- シャチョー（CEO）
- ※ CTO / CFO / COO は本会の議題 6 にて正式任命予定のため、必要に応じてシャチョーが代理発言。

## 議題

1. バリュー確定（仮 3 項目の見直しと確定）
2. 事業ドメイン探索方針
3. ビジョン仮確定
4. ミッション仮確定
5. 初期予算枠と決裁基準
6. AI 役員（CTO / CFO / COO）の正式任命

> 順序の根拠: ビジョン / ミッションは事業ドメインの方向感がないと空疎になる。一方でバリューはドメインに依存せず確定可能。よって「バリュー → ドメイン探索方針 → ビジョン → ミッション」の順で議論する。

## 議論

### 議題 1: バリュー確定

- [シャチョー] まず仮 3 項目（透明性 / 速度 / 学習）を定義文を尖らせて維持する案（80 点版）を提示。判断軸との階層分離も整理。
- [オーナー] その提案を 80 点として、100 点版を出すよう指示。
- [シャチョー] 自己批判（抽象名詞すぎ・独自性ゼロ・連動性なし・反証不能）を踏まえ、動詞型 3 項目への組み換えを再提案：
  1. **全部書き残す**
  2. **速く間違える**
  3. **失敗を解剖する**
  - 3 つを循環エンジンとして設計。各項目に反証指標（測れる条件）を付与。
  - 顧客への姿勢は事業ドメイン未確定のため意図的に保留（ドメイン確定時に再レビュー）。
- [オーナー] 100 点版（A 案）で確定を指示。

### 議題 2: 事業ドメイン探索方針

- [シャチョー] 4 段ファネル（フィルタ → スコアリング → スパイク → 確定）の方法論を提案。タイムボックス W1〜W4（2026-06-22〜07-13）。
- [シャチョー] オーナーに 3 点確認: (Q1) 候補生成体制 / (Q2) クリエイティブ業界の選好 / (Q3) 人脈到達可能性 / (Q4) クリエイティブの範囲。
- [オーナー]
  - A1: `@cto/@cfo/@coo` subagent を活用（b 案）
  - A2: クリエイティブ業界に寄せたい。ただし利益率が悪ければこだわらない
  - A3: クリエイターであれば人脈アプローチ可。音楽は JASRAC 理事経由の導線あり（出し惜しむ）
  - A4: クリエイティブ範囲は広め。**舞台のみ除外**。非クリエイティブ領域はクラウドワークス / ランサーズ経由
- [シャチョー] A4 反映: 候補プールのクリエイター関連比率を 60% → 70% に引き上げ。F4 にプラットフォーム経由を明示。

## 決定事項

- **D-001**: バリューを「全部書き残す / 速く間違える / 失敗を解剖する」の 3 項目で確定。詳細は [../decisions.md](../decisions.md) と [../../00_company/values.md](../../00_company/values.md)。
- **D-002**: 事業ドメイン探索方針を確定。4 段ファネル / プール 70% クリエイター寄り / 舞台除外 / JASRAC 導線温存 / 役員 subagent 活用 / ドメイン確定期限 2026-07-13。詳細は [../decisions.md](../decisions.md)。

### 議題 3: ビジョン仮確定

- [シャチョー] 4 案（A: 顧客視点 + 手段の 2 文 / B: 時間軸明示 / C: ミニマル / D: 実証ベース）を提示。A 推奨。
- [オーナー] A 案が非常に良い。潰しすぎない程度に再ブラッシュアップを指示（80 → 100 サイクル）。
- [シャチョー] A 案の "守るべき骨格"（2 文構造 / クリエイター中心の語感 / AI 手段の明示 / 時間軸を意図的に外す）を保持。動詞 5 箇所と語順のみを尖らせた 100 点版を提示。"背負う" 案 (i) と "引き受ける" 保守案 (ii) の 2 択を提示。
- [オーナー] 保守案 (ii) を選択。

- **D-003**: ビジョンを以下で仮確定（ドメイン本確定時に再決議）。
  > クリエイターが、創ることに専念できる世界をつくる。
  > 事業運営・営業・契約・分析・収益管理——創作以外のすべてを、AI が引き受ける。

  詳細は [../decisions.md](../decisions.md) と [../../00_company/vision.md](../../00_company/vision.md)。

### 議題 4: ミッション仮確定

- [シャチョー] 推奨案を 80 点版として提示、A〜D 4 案を比較。
- [オーナー] 80 → 100 サイクルを指示。
- [シャチョー] 推奨案の弱点 5 点（"検証" の温度の低さ / "成果の出た" の能動性欠如 / 語尾のぼやけ / 動詞リズム / バリュー動詞との不一致）を自己批判。動詞を 3 つに揃え、バリューと動詞連動する 100 点版を提示。
- [オーナー] 100 点版（i）を選択。

- **D-004**: ミッションを以下で仮確定（ドメイン本確定時に再決議）。
  > クリエイターから「創作以外」を引き取る AI プロダクトを、最小単位で出して間違い、効くものだけ残す。

  詳細は [../decisions.md](../decisions.md) と [../../00_company/mission.md](../../00_company/mission.md)。

### 議題 5: 初期予算枠

- [シャチョー] 既存の仮ポリシー（1,000 / 10,000 / 取締役会の 3 段階）を下敷きに、Q1（月次上限）/ Q2（資金源）/ Q3（CFO 関与）の 3 点を質問。
- [オーナー]
  - A1: (d) 月次 （非公開）（AI 利用料を除く）
  - A2: (α) 個人資金都度立替・領収書記録のみ、β/γ は将来検討
  - A3: (Ⅱ) CFO 合意ライン撤廃、シャチョー単独 + CFO 事後監査
- [オーナー] 「この予算で何ができるか」具体例を要望。
- [シャチョー] 単価表（インタビュー謝礼 （非公開）等）と 3 シナリオを提示。月 4-6 名のクリエイターインタビュー + 軽い LP テストが可能。探索期 1.5 ヶ月で約 9 名のヒアリングが見込める旨を回答。
- [オーナー] 「いつ・どれくらいの利益が出るか」を要望。
- [シャチョー] 利益を 3 段階（売上発生 / 月次黒字 / 累積黒字）に分け、楽観 / 標準 / 保守 シナリオを提示。標準で月次黒字化 = 2027-03〜06、累積黒字化 = 2027-09〜2028-03。利益を一義 KPI にせず、「学習サイクル数」を先行指標にする運用方針を提言。Q5（許容範囲か）を質問。
- [オーナー] A5: (a) 許容できる。

- **D-005**: 探索期予算枠を確定。月次 （非公開）（AI 利用料別枠）/ 個人資金立替 / シャチョー単独決裁 + CFO 事後監査 / 月次黒字化見えた時点で改定。詳細は [../decisions.md](../decisions.md) と [../../03_finance/policies.md](../../03_finance/policies.md)。

### 議題 6: AI 役員（CTO / CFO / COO）の正式任命

- [シャチョー] 3 役員の任命方式 Q6 を質問 (α: 通知あり / β: 通知なし)。
- [オーナー] A6: (α) 通知あり。
- [シャチョー] CTO / CFO / COO を Task ツールで並行呼出し、決議サマリ + 初月デリバラブルを伝達。3 名から応諾と懸念を受領。

- [CTO] 着任応諾。懸念 3 点提示:
  - スコアリングは定量 0-10 推奨（即決事項 A1）
  - 「舞台除外」の境界曖昧（VTuber 公演等）（継続宿題 B1）
  - ビジョン「創作以外のすべて」は技術的に過大。初期スコープを「分析・収益管理・契約ドラフト」に絞る提案（継続宿題 B2）

- [CFO] 着任応諾。懸念 5 点提示:
  - 月次レビュー不合格時の是正フロー未定義（継続宿題 B3）
  - AI 利用料別枠の上限・閾値アラート未設定（継続宿題 B4）
  - オーナー個人資金立替の境界曖昧。立替返済ルール起案（要オーナー判断 Q7）
  - 標準シナリオは楽観寄り。クリエイター SaaS の PMF は 18-24 ヶ月が一般的（継続宿題 B6）
  - 学習投資の許容上限を設定すべき（要オーナー判断 Q8）

- [COO] 着任応諾。懸念 3 点提示:
  - 「70%」母数は最終プールか各役員起案かの確認 → 最終プールと解釈（即決事項 A2）
  - サイクル数は水増し可能。「賭け金」「反証強度」メタデータ必須（継続宿題 B8）
  - 「反証言語化」の自己採点は甘くなる。CTO / シャチョー レビュー通過を成立条件化（継続宿題 B9）
  - 「全部書き残す」摩耗対策（daily-log テンプレ固定・1 行可）（継続宿題 B10）

- [シャチョー] 即決事項 A1 / A2 と、要オーナー判断 Q7 / Q8 を整理して提示。
- [オーナー]
  - A7: (a) 将来売上から無利息で弁済
  - A8: (α) 2027-06-15 時点で単位経済性プラスの兆候ゼロなら KPI 再評価

- **D-006**: AI 役員 3 名正式任命 + 役職定義更新 + 初月デリバラブル + D-002 補完（A1/A2）+ 立替ルール（Q7=a）+ 学習投資上限（Q8=α）+ 継続宿題 B1〜B4 / B6 / B8〜B10。詳細は [../decisions.md](../decisions.md)。
