# 取締役会議事録

## ファイル名規約

- 通常: `YYYY-MM-DD.md`
- 月末定例: `YYYY-MM-EOM.md`
- 臨時: `YYYY-MM-DD-extra.md`

## 議事録テンプレート

```markdown
# 取締役会議事録 YYYY-MM-DD

## 出席者
- オーナー
- シャチョー（CEO）
- [CTO] [CFO] [COO]（出席した者）

## 議題
1. ...
2. ...

## 議論
- [シャチョー] ...
- [オーナー] ...
- [CTO] ...

## 決定事項
- D-NNN: ...
- D-NNN: ...

## 次回への持ち越し
- ...
```

## 運用

- 議事録を作成したら、対応する決議を [../decisions.md](../decisions.md) に追記する（番号で相互参照）。
- 議題を [../agenda.md](../agenda.md) から消化済みのものは削除する。
