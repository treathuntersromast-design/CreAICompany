# インシデント記録

発生した事案の記録と振り返り。

ファイル名: `YYYY-MM-DD_<タイトル>.md`

## テンプレート

```markdown
# インシデント YYYY-MM-DD: <タイトル>

## 概要
（何が起きたか、1〜2 文）

## 影響
（誰に / 何に / どれくらいの影響があったか）

## 時系列
- HH:MM 発生
- HH:MM 検知
- HH:MM 初動
- HH:MM 復旧

## 根本原因
（なぜ起きたか）

## 対策
- 即時: ...
- 恒久: ...

## 学び
（次に同じことを起こさないために）

## 関連
- リスク台帳更新: R-NNN
- 決議: D-NNN
```
