# ヒアリング時 5 分デモ台本

スパイク S-2 / ヒアリング相手: インディーゲーム開発者
所要時間: 5 分（実 API モードなら 30-60 秒で生成完了する見込み）

## 事前準備（ヒアリング 5 分前）

1. `.env` に `ANTHROPIC_API_KEY` 設定 / `DUMMY_MODE=false`
2. `streamlit run app.py` で起動
3. ブラウザを画面共有用に整理（タブを閉じる、URL バーを隠す等）
4. **ヒアリング相手のゲーム情報をその場で入力する場合は、事前に簡易ヒアリング**（タイトル・ジャンル・コアメカニクスの 3 つだけは予めもらっておく）

## デモ進行（5 分）

### 0:00-0:30 セットアップ説明

> 「今からお見せするのは、ゲーム開発者さんが Steam ストアページを作る時の "コピーライティング / タグ / スクショ配置 / トレーラー" を AI が一気に提案するツールです。完成度ではなく、 *もし手元にあったら使いますか* というのを聞きたくて作りました。」

### 0:30-1:30 入力（相手のゲーム情報を入れる or サンプル使用）

- 「サンプルをロード」ボタンで `Lumencraft Echo`（架空タイトル）のデータを表示
- **もし相手が自分のゲーム情報を入れたい場合**:
  - サイドバーに直接入力（タイトル・ジャンル・コアメカニクス・ターゲット層）
  - 既存のストア URL があれば入れる（「これを参考にして改善案を出すこともできます」）
  - スクショは事前準備が間に合わなければサンプル説明で代用

### 1:30-2:00 生成ボタン押下

> 「Claude（Anthropic の AI）に 4 タスクを並列に投げます。説明文・タグ・配置案・トレーラー、それぞれ別プロンプトで生成。30 秒くらいかかります。」

待ち時間中の会話:
> 「ストアページの最適化って、普段どれくらい時間かけてます？」
> 「多言語対応、現状どうやってますか？」

### 2:00-3:30 結果ツアー（タブ切り替え）

1. **説明文タブ**: 「5 言語出ます。日本語と英語を見てください。中華圏・韓国語まで一気に出るので、グローバル展開の足がかりにも」
2. **タグタブ**: 「Steam のタグは発見性に直結します。優先順位と理由付きで出るので、自分で選ぶ判断材料になります」
3. **スクショ配置タブ**: 「これが地味に効くやつです。1 枚目を間違えると CTR が大きく落ちる、というデータがあります」
4. **トレーラータブ**: 「30 秒版と 60 秒版の台本。動画編集はご自身でやる必要がありますが、構成案として」

### 3:30-4:30 「実際に使うとしたら」を聞く

質問項目（必ず全部聞く）:

1. **「今のリリース予定があれば、今日のこの出力をそのまま使えそうですか？」**
2. **「もし完璧じゃないとしても、たたき台として時短になりますか？」**
3. **「いくらまでなら払いますか？」** 提示順:
   - 「リリース前 1 回 （非公開）（買い切り）」
   - 「月額 （非公開）（複数タイトル対応）」
   - 「いくらが妥当だと思いますか？」と逆質問
4. **「もし無料だとしたら、どこを改善してほしい？」**
5. **「他の人にも教えたいと思いますか？」**

### 4:30-5:00 クロージング

> 「正直にダメ出しもらった方が嬉しいです。今後この事業をやるかどうかをこの 2 週間で決めるので。」

謝礼受け渡し・お礼。

## 注意（CTO セルフチェック）

- **「すごい」と言わせない**: ヒアリングで一番多い罠。"払うか" を聞くまでが仕事
- **無料 vs 有料の境界を必ず確認**: 「無料なら使う」は買わない人のシグナル
- **不満が出たら掘り下げる**: 「具体的にどこが？」「何枚生成すれば足りる？」
- **ウィッシュリスト改善の実数値を期待されたら**: 「現状の MVP は提案までです。効果検証は別フェーズで取り組みます」と正直に伝える
