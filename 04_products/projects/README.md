# プロジェクト

進行中のプロジェクトをここに置く。

## ディレクトリ規約

```
projects/<slug>/
├── brief.md      # 何を、誰のために、なぜやるか
├── roadmap.md    # マイルストーン
└── status.md     # 現在の進捗、ブロッカー
```

`<slug>` は英小文字 + ハイフンの kebab-case。

## brief.md テンプレート

```markdown
# <プロジェクト名>

## 目的
（このプロジェクトで何を達成するか、1〜2 文）

## 対象顧客
（誰の何を解決するか）

## 成功条件
（何が起きたら成功か。定量的に）

## 関連 OKR
- YYYY-Qx の KR-N: ...

## 関連決議
- D-NNN: プロジェクト承認
```

## roadmap.md テンプレート

```markdown
# ロードマップ

| マイルストーン | 完了予定 | 状態 |
|---|---|---|
| M1: ... | YYYY-MM-DD | pending |
| M2: ... | YYYY-MM-DD | pending |
```

## status.md テンプレート

```markdown
# ステータス（YYYY-MM-DD 時点）

## 進捗
- ...

## ブロッカー
- ...

## 次の一手
- ...
```
