# スパイク S-1: 同人/インディー楽曲メタデータ整理 SaaS

確定: 2026-06-15（[D-008](../../01_board/decisions.md)）

## 概要

| 項目 | 内容 |
|---|---|
| **対象顧客** | 自主リリースのインディー音楽家・ボカロ P・トラックメイカー |
| **困りごと** | 各配信ストア（Spotify / Apple Music / TuneCore / DistroKid）に出すたびに ISRC / ジャンルタグ / クレジット / 歌詞ライセンス情報を手入力。1 曲 30〜60 分溶ける |
| **解決手段** | 楽曲ファイル（wav / mp3）+ 簡易テキスト投入 → AI がメタデータ生成 → 各ストア向け CSV / API ペイロードに整形 |
| **収益モデル** | SaaS 月額（推定 （非公開）〜3,000/月） |

## 検証仮説

> 「楽曲ファイル投入 → AI 生成メタデータで、1 曲あたり準備時間が **30 分以上削減** されるか」

## スパイク計画

| 項目 | 内容 |
|---|---|
| 主担当 | CTO（MVP 設計・実装）+ COO（顧客接触・ヒアリング） |
| 期間 | 2026-06-16 〜 2026-06-29（2 週間） |
| 成果物 | (a) MVP プロトタイプ 1 / (b) クリエイター 5 名のヒアリング記録 |
| 想定支出 | （非公開）（謝礼 （非公開） × 5 名） |

## 顧客獲得導線

- オーナー直接人脈のクリエイター（5 名以下なら 5 日以内に到達可・[D-002](../../01_board/decisions.md) F4 通過）
- 不足分はボカロ系 X コミュニティから補充
- **JASRAC 理事人脈は温存**（このスパイクでは使わない）

## 撤退条件

5 名中 **0 名** が「金を払いたい / 強い興味」を示さなかったら却下。

## 評価基準（ヒアリング後）

| 評価 | 判定 |
|---|---|
| 5 名中 3 名以上が「払いたい / 強い興味」 | 強い継続シグナル（ドメイン本確定の有力候補） |
| 5 名中 1〜2 名が「払いたい」 | 中シグナル（条件付き継続。スコープ修正検討） |
| 5 名中 0 名が「払いたい」 | 撤退（[2026-06-15-domain-candidates.md](2026-06-15-domain-candidates.md) で代替候補から再選定） |

## バリュー連動（学習サイクル）

- バリュー「速く間違える」: 2 週間で 1 ループ完結
- バリュー「失敗を解剖する」: 結果が撤退判定でも、撤退理由を **次回スパイク選定時の判断ルール** として残す
- バリュー「全部書き残す」: ヒアリング録音 + 文字起こし + 所感を本ファイルに追記
