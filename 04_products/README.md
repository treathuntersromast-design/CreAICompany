# 04_products — プロダクト・事業開発

事業アイデアと進行中プロジェクトを置く。

- `ideas/INBOX.md` — アイデア溜め込み（1 行 1 アイデア）
- `projects/<slug>/` — 進行中プロジェクト
  - `brief.md` — プロジェクト概要
  - `roadmap.md` — ロードマップ
  - `status.md` — 現在の進捗状況

## 昇格フロー

INBOX → 週次レビューでシャチョーが昇格判断 → 取締役会で承認 → `projects/<slug>/` を作成

## OKR との連携

各プロジェクトは、対応する OKR（[../02_strategy/okrs/](../02_strategy/okrs/)）の KR とリンクする。
