# バリュー

当社が日々の業務で守る 3 つの行動指針。判断に迷ったときの一次基準。

確定: 2026-06-15（[D-001](../01_board/decisions.md)）

## 1. 全部書き残す

判断・対話・迷い・失敗を、即座に文字で残す。記録は副業務ではなく**本業務**。

- **共通言語**: 「書かれていないことは存在しない」
- **反証指標**: 判断後 24 時間以内に該当ファイルへ追記されているか
- **対外言い換え**: 「ドキュメント駆動の経営」

## 2. 速く間違える

完成を目指さない。次の学習を最短で得るための最小単位を出す。「正解の作成」ではなく**「間違いの早期発見」**が目的。

- **共通言語**: 「成功を急ぐな、失敗を急げ」
- **反証指標**: 仮説 → 出力 → 反証 のサイクルが 2 週間以内に 1 周回ったか
- **対外言い換え**: 「速い学習サイクル」（外部発信では誤解回避のためこの表現を使う）

## 3. 失敗を解剖する

失敗は事故報告ではなく構造分析の対象。「なぜ失敗したか」ではなく**「次にどう判断するか」**を必ず書く。記録しただけは解剖ではない。

- **共通言語**: 「失敗のあとに新しい判断ルールが 1 行も増えていないなら、それは失敗を捨てている」
- **反証指標**: 失敗ごとに「次回の判断ルール」が 1 行以上書かれているか
- **対外言い換え**: 「失敗からの学習を制度化する」

## 3 つの関係

```
全部書き残す  →  速く間違える  →  失敗を解剖する  ┐
       ↑                                              │
       └──────────────────────────────────────────────┘
                  （解剖結果を書き残す）
```

3 つは並列ではなく**循環エンジン**として機能する。1 つ欠けたらサイクルが止まる。

## 判断軸との関係

本バリューは「日々の振る舞い方（HOW）」を定める。価値が衝突したときの優先順位（WHICH WHEN CONFLICT）は [CLAUDE.md](../CLAUDE.md) の判断軸（長期 > 短期 / 顧客 > 内部 / 学習 > 即時 / 透明性 > 体裁）を参照。

## 改廃

- 事業ドメイン確定時に再レビュー予定（顧客への姿勢を追加すべきかを判断）。
- 改廃には取締役会決議が必要。
